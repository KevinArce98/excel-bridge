Read & write .xlsx, without the weight.

A lightweight, tree-shakeable spreadsheet toolkit for TypeScript. Full read and write (styling, formulas, conditional formatting) in the browser and Node.js, without pulling in ExcelJS or SheetJS.

Everything you need to move a spreadsheet.

One typed API for both directions and both runtimes, from a two-line export to million-row streaming.

A1

Full read & write

Styling, fonts, borders, formulas, dates, merged cells, freeze panes, conditional formatting and data validation — parsed back losslessly for the features it writes.

D1

Zero heavy dependencies

No ExcelJS or SheetJS under the hood, just fflate and fast-xml-parser. A micro-package architecture ships only what you import.

A2

Browser & Node

One API for File/Blob in the browser and Buffer in Node.js.

C2

Streaming writer

Export a million rows from a sync or async iterable without holding them in memory.

E2

Signed releases

Every version is published to npm with build provenance.

A3

High-level Workbook API

Load an existing file, edit cells, styles, merges and freeze panes, then save it back. No rebuilding sheet data by hand.

D3

TypeScript-first, tree-shakeable

Complete types and IntelliSense for every export, in both ESM and CJS. Import one helper and bundle only that.
